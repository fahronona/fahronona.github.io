Kebijakan Privasi

Terakhir diperbarui: 27 Juli 2026

Aplikasi Hitung BMI ("Aplikasi") menghargai privasi pengguna. Kebijakan Privasi ini menjelaskan bagaimana Aplikasi mengelola data Anda saat menggunakan layanan kami.

Ringkasan singkat: Aplikasi Hitung BMI tidak memerlukan pendaftaran atau login, tidak mengumpulkan data pribadi, dan seluruh riwayat perhitungan BMI disimpan sepenuhnya di perangkat Anda sendiri.

1. Data yang Kami Kumpulkan

Aplikasi Hitung BMI tidak mengumpulkan, tidak mengirim, dan tidak menyimpan data pribadi Anda ke server manapun. Aplikasi ini tidak memiliki fitur login, registrasi akun, atau autentikasi dalam bentuk apapun.

2. Penyimpanan Data Riwayat Perhitungan

Untuk kenyamanan pengguna, Aplikasi menyimpan riwayat hasil perhitungan BMI (seperti berat badan, tinggi badan, dan hasil BMI) menggunakan basis data lokal SQLite yang tersimpan langsung di perangkat Anda. Data ini:

  • Tidak pernah dikirim atau diunggah ke server, cloud, atau pihak ketiga manapun
  • Hanya dapat diakses melalui Aplikasi di perangkat Anda sendiri
  • Sepenuhnya berada di bawah kendali Anda
  • Akan terhapus secara otomatis jika Anda menghapus (uninstall) Aplikasi dari perangkat

3. Izin Aplikasi (Permissions)

Aplikasi Hitung BMI tidak memerlukan izin khusus seperti akses kamera, lokasi, kontak, atau mikrofon untuk menjalankan fungsinya.

4. Berbagi Data dengan Pihak Ketiga

Karena seluruh data disimpan secara lokal di perangkat pengguna, Aplikasi tidak membagikan data apapun kepada pihak ketiga, termasuk untuk keperluan iklan, analitik, maupun pemasaran.

5. Keamanan Data

Meskipun data disimpan secara lokal dan tidak dikirim ke luar perangkat, kami menyarankan pengguna untuk menjaga keamanan perangkat mereka sendiri (misalnya dengan kunci layar) guna melindungi data yang tersimpan di dalamnya.

6. Hak Pengguna atas Data

Karena data sepenuhnya tersimpan di perangkat Anda, Anda memiliki kendali penuh untuk:

  • Menghapus riwayat perhitungan kapan saja melalui fitur yang tersedia di dalam Aplikasi (jika ada)
  • Menghapus seluruh data dengan cara meng-uninstall Aplikasi

7. Privasi Anak

Aplikasi ini tidak ditujukan khusus untuk anak-anak di bawah usia 13 tahun dan tidak secara sengaja mengumpulkan data pribadi dari anak-anak, mengingat Aplikasi memang tidak mengumpulkan data pribadi apapun.

8. Perubahan Kebijakan Privasi

Kebijakan Privasi ini dapat diperbarui dari waktu ke waktu. Perubahan akan tercermin melalui tanggal "Terakhir diperbarui" di bagian atas halaman ini. Kami menyarankan Anda untuk meninjau halaman ini secara berkala.
